# Personalized Career Recommendation System

## Overview

The Personalized Career Recommendation System is an application designed to suggest suitable career paths based on a user’s skills, interests, and preferences. The system analyzes input data and provides tailored recommendations to help users make informed career decisions.

---

## Tech Stack

* Frontend: React.js
* Backend: Spring Boot (REST APIs)
* Database: MySQL
* Additional Concepts: Machine Learning / Rule-based logic

---

## System Architecture

The application follows a layered architecture:

Frontend → REST APIs → Backend Services → Database

* Frontend collects user input such as skills, interests, and preferences
* Backend processes the data and applies recommendation logic
* Database stores user profiles and recommendation results

---

## Core Features

* Personalized career suggestions based on user input
* Skill-based and interest-based matching
* User profile management
* Dynamic recommendation generation
* Scalable backend architecture

---

## Recommendation Logic

The system uses rule-based logic (or machine learning, if applicable) to match user profiles with suitable career paths. Recommendations are generated by analyzing factors such as:

* Skills
* Interests
* Domain preferences

---

## Database Design

### Users Table

* user_id (Primary Key)
* name
* skills
* interests

### Recommendations Table

* recommendation_id (Primary Key)
* user_id (Foreign Key)
* career_path
* score

---

## How to Run

### Backend

1. Navigate to backend directory
2. Configure MySQL in application.properties
3. Run Spring Boot application

### Frontend

1. Navigate to frontend directory
2. Install dependencies:

   ```bash
   npm install
   ```
3. Start the application:

   ```bash
   npm start
   ```
